# Korean feedback voice

Generated locally with Piper and the `ko_KR-kss-medium` single-speaker Korean voice.
This is a different voice from the operating system's Microsoft Heami voice.

- Model: https://huggingface.co/rhasspy/piper-voices/tree/main/ko/ko_KR/kss/medium
- Dataset: Korean Single Speaker Speech (KSS), https://www.kaggle.com/datasets/bryanpark/korean-single-speaker-speech-dataset
- Dataset/model-card license: CC BY-NC-SA 4.0, https://creativecommons.org/licenses/by-nc-sa/4.0/
- Engine: https://github.com/OHF-Voice/piper1-gpl (GPL-3.0)
- Generation: length_scale 1.13, noise_scale 0.5, noise_w_scale 0.65, volume 0.85.

The WAV files contain only fixed application feedback for scores 0–100. They contain no student audio. Retain attribution and the non-commercial/share-alike terms when redistributing these assets.
